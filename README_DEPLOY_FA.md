# سایت مستقل b-chat

این پوشه یک پروژه React + Vite مستقل است و باید در مخزن GitHub و پروژه Vercel **مجزا** منتشر شود. نسخه این سایت در کد ثابت شده: `b-chat`.

## راه‌اندازی
1. محتویات همین پوشه (نه پوشه والد) را در مخزن خصوصی GitHub بارگذاری کنید.
2. در Vercel از Add New → Project مخزن را Import کنید. Framework = Vite، Build = `npm run build`، Output = `dist`.
3. برای نسخه‌های دارای چت‌بات، در Vercel → Settings → Environment Variables مقدار `OPENAI_API_KEY` را اضافه کنید و Deploy مجدد انجام دهید. `OPENAI_MODEL` اختیاری است. کلید را در GitHub یا کد فرانت‌اند نگذارید.
4. آدرس اصلی دامنه `/` را باز کنید؛ این سایت فقط نسخه `b-chat` را نشان می‌دهد.
5. تست کنید: فهرست محصولات، جزئیات، سبد خرید، ثبت آزمایشی، موبایل، و در نسخه chat پاسخ API.

## محدودیت‌های فعلی
- سفارش‌ها ذخیره دائمی ندارند و پرداخت واقعی وجود ندارد.
- تصاویر محصول شماتیک هستند.
- build کامل در این محیط تأیید نشده؛ پیش از لانچ `npm install && npm run build && npm run test:api` اجرا شود.
- قبل از اجرای پژوهش، تفاوت‌های معماری A/B و عملکرد LLM بازبینی شوند.
